# A/B-тест геймификации в EdTech

Учебный проект по кейсу VK Education Projects.

На образовательной платформе для школьников тестировали новую механику: достижения и награды за выполнение заданий. Нужно было проверить, повлияла ли она на Completion Rate и возвращение пользователей, а затем решить, стоит ли запускать её для всех.

## Анализ

Работала с двумя таблицами: пользователи с распределением по группам A/B и логи событий.

При проверке данных обнаружила 8 пользователей, попавших в обе группы, 2 дубликата событий и 12 пользователей с аномально высокой активностью. После очистки проверила распределение по группам, рассчитала основные метрики и провела статистические тесты.

Отдельно сравнила результаты по классам с 5-го по 11-й.

Использовала Python (pandas, SciPy, statsmodels), SQL через DuckDB и Matplotlib для графиков.

## Что получилось

В группе с геймификацией показатели оказались выше:

- Completion Rate: 34,6% → 43,8%
- D7: 72,7% → 78,0%
- D14: 28,8% → 36,2%

Все три различия статистически значимы.

Но при анализе по классам выяснилось, что результаты неодинаковые. В 5-9 классах Completion Rate вырос, а в 10–11, наоборот, снизился на 4–6 процентных пунктов.

Поэтому я бы не рекомендовала запускать геймификацию сразу для всех. Для 5–9 классов можно рассмотреть ограниченный запуск, а для старшеклассников сначала разобраться в причинах снижения показателя.

## Ограничения

В данных нет идентификаторов отдельных домашних заданий, поэтому Completion Rate рассчитывала по событиям начала и завершения заданий. Точная логика формирования D7 и D14 также неизвестна, их нельзя уверенно трактовать как классическое удержание после регистрации.
